# WALLOW — Hippo Dating App

Find your mudmate. A playful client-side dating experience for hippos.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## What’s included

- Brand-first hero (WALLOW)
- Swipe deck of mock hippo profiles (Like / Pass)
- “It’s a Wallow!” match modal when they like you back
- Matches list persisted in `localStorage`
